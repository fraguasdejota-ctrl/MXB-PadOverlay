# MXB-PadOverlay
MXB PadOverlay - Standalone Transparent Controller HUD (No OBS / Streamlabs Required)
Description:
Hey everyone! I created this lightweight standalone desktop tool for riders who want to see their controller inputs directly over the screen or share their screen directly on Discord without having to keep OBS or Streamlabs open in the background.

Key Features:

100% Standalone (.exe): No Python installation, browser tabs, or OBS window captures needed.

True Transparency: Clean floating overlay with zero background clutter.

Plug & Play: Just connect your controller, run the executable, and ride.

Zero FPS Drop: Minimal CPU and RAM usage compared to streaming software.

How to use:

Connect your controller to your PC before opening the app.

Extract the .zip file and run MXB_PadOverlay.exe.

(Optional) Run MX Bikes in Windowed or Borderless mode so the overlay stays visible on top.

Antivirus Note / VirusTotal:
Because this tool is packaged from Python into a standalone .exe using PyInstaller, Windows SmartScreen might show an "Unknown Publisher" warning on first launch. Just click More Info -> Run anyway.
